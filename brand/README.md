# Facthor8 brand assets

This directory contains the approved Facthor8 identity system.

## Master files

- `facthor8-horizontal.svg`: primary logo for light backgrounds.
- `facthor8-horizontal-reverse.svg`: transparent reverse logo for dark backgrounds.
- `facthor8-horizontal-dark.svg`: logo on a Deep Navy background.
- `facthor8-horizontal-navy.svg`: monochrome navy version.
- `facthor8-horizontal-white.svg`: monochrome white version.
- `facthor8-symbol.svg`: primary symbol.
- `facthor8-symbol-white.svg`: white symbol.

High-resolution PNG exports are stored in `png/`. The editable and PDF identity manuals are stored in `manual/`.
Production-ready SVG files with typography converted to vector paths are stored in `outlines/`. These are the preferred files for suppliers, printing and any environment where the original font cannot be guaranteed.

## Approved palette

- Midnight Navy: `#06294D`
- Deep Navy: `#041C34`
- Human Green: `#00D39A`
- Mineral White: `#F7FAFC`
- Signal Slate: `#7890A5`

Do not alter the symbol geometry, recolor individual segments, move the human element, or recreate the wordmark with another typeface.
